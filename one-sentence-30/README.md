# 한 문장 30번

하루 **한 문장**을 정하고, 조건을 바꿔 가며 **30번** 영어로 말해 보는 연습 페이지입니다.
문장을 외우는 대신 아는 문장을 바꿔 쓰는 힘을 기르는 것이 목표입니다.

## 파일

| 파일 | 역할 |
|------|------|
| `index.html` | 화면과 동작 전부 (서버 없음) |
| `data/sentences.js` | 문장과 30개 변형 문제 |

## 여는 방법

- **그냥 열기**: `index.html` 을 브라우저로 엽니다. 듣기와 입력은 바로 됩니다.
- **음성 입력(🎤)까지 쓰려면** https 나 localhost 로 열어야 합니다. 파일로 직접 열면 마이크 권한이 막힐 수 있습니다.
  ```bash
  cd random-card && python3 -m http.server 8000
  # http://localhost:8000/one-sentence-30/
  ```
  GitHub Pages 에 올려도 됩니다.
- 음성 입력은 **크롬**에서 가장 잘 됩니다. 사파리는 지원이 들쭉날쭉합니다.

## 학습 흐름

1. 홈에서 **오늘의 문장**을 고릅니다. 안 해 본 문장이 먼저 나오고, 다 해 봤으면 가장 오래전에 한 문장이 나옵니다.
2. 한국어 문제를 보고 영어로 **말하거나(🎤) 입력**한 뒤 확인합니다.
3. 정답과 단어 단위로 비교해서 보여 줍니다. 초록은 빠진 말, 빨강은 다른 말입니다.
   축약형(I'm = I am)과 숫자(2 = two)는 같은 것으로 봅니다.
4. 스스로 채점합니다: **○ 맞음 / △ 애매 / ✕ 틀림**. 정답과 완전히 같으면 ○ 이 미리 선택됩니다.
   **✕ 는 맨 뒤에 한 번 더** 나옵니다.
5. 다 끝나면 점수(○=1, △=0.5, 첫 시도 기준)와 30문장 목록이 나옵니다.
   **▶ 전체 듣기**로 30문장을 이어서 들을 수 있고, 한국어도 함께 읽게 할 수 있습니다.

### 30문제 구성

| 번호 | 단계 |
|------|------|
| 1~5 | 주어 바꾸기 |
| 6~10 | 시제·형태 |
| 11~15 | 부정·의문 |
| 16~20 | 동사 바꾸기 |
| 21~25 | 상황 적용 |
| 26~30 | 자유 응용 (정답이 여러 개라 영어는 "예시"로 표시) |

## 문장 추가하기

`data/sentences.js` 의 배열에 항목을 하나 더 넣습니다. `drills` 는 반드시 30개여야 하고, 위 단계 순서를 따릅니다.

```js
{
  id: "used-to",                       // 고유 값 (진도 저장 키)
  en: "I used to live in Busan.",      // 기본 문장
  ko: "나 예전에 부산 살았어.",
  point: "used to + 동사원형 = 예전에 ~했다 (지금은 아님)",
  drills: [
    ["한국어 문제", "English answer.", "조건(선택)"],
    // ... 30개
  ]
}
```

## 저장과 기기 간 동기화

먼저 이 기기의 `localStorage` 에 저장하고, **동기화 코드**가 있으면 Firebase 에도 올립니다.
노트북에서 12번까지 하다가 핸드폰을 열면 13번부터 이어 할 수 있습니다.

- 메인 앱(`../index.html`)과 **같은 Firebase 프로젝트, 같은 문서** `wrongCardsSync/{동기화 코드}` 를 쓰고 **`s30` 필드만 추가**합니다. Firestore 규칙은 바꾸지 않았습니다.
- 동기화 코드도 메인 앱과 같은 키(`english-card-sync-code`)를 씁니다. 같은 사이트(예: GitHub Pages)에서 열면 메인 앱에 넣은 코드를 그대로 씁니다. 코드가 없으면 홈 › 설정에서 넣습니다.
- 홈을 열 때, 채점할 때(1.2초 모아서), 연습을 마칠 때, 앱을 내리거나 다시 열 때, 인터넷이 다시 연결될 때 동기화합니다.
- 오프라인이면 이 기기에만 저장하고, 다음 동기화 때 올립니다.

| localStorage 키 | `s30` 필드 | 내용 | 여러 기기 기록을 합치는 규칙 |
|----|----|------|------|
| `s30-progress` | `progress` | 문장별 완료 횟수, 마지막 날짜, 점수, `ts` | 문장별로 `ts` 가 최신인 쪽 |
| `s30-days` | `days` | 완료한 날짜 (연속 학습일) | 합집합 |
| `s30-session` | `session` (JSON 문자열) | 진행 중인 연습. 끝나면 `{cleared, ts}` 로 남김 | `ts` 가 최신인 쪽 (마지막에 연습한 기기) |
| `s30-settings` | 없음 | 읽기 속도, 자동 읽기, 자동 확인 | 기기마다 따로 |

`session` 을 문자열로 저장하는 이유: merge 저장 시 Firestore 가 객체를 깊게 합쳐서, 이전 연습의 채점 결과가 새 연습에 섞이는 것을 막기 위해서입니다.
